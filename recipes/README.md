# Recipes

定型依頼に対して「どのtoolを、どの順で、どこまで実行するか」を固定するassistant向け手順。

toolが**取得・変換の実装**、recipeが**作業完了条件**を担当する。

## Index

| Recipe | Use for |
| --- | --- |
| [reddit-research.md](reddit-research.md) | Redditを調べる、評判・体験談・雑談を拾う |
| [x-image-research.md](x-image-research.md) | Xで画像を探し、投稿・画像まで確認する |
| [source-deep-dive.md](source-deep-dive.md) | ふたば/X/Reddit等を横断して過去事例を深掘りする |

未来のassistantは、依頼がこのパターンに一致する場合、まず該当recipeを読み、必要なtoolだけ使う。
